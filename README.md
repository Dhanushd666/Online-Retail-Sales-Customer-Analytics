# Online Retail Sales & Customer Analytics

## Project Overview
An end-to-end Power BI project using the UCI Online Retail dataset to analyse sales performance, product trends, customer behaviour, returns, and international markets.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel

## Key Analysis
- Sales and revenue trends
- Product performance
- Customer purchase frequency and value
- One-time versus repeat customers
- Returns and cancellation analysis
- International market comparisons

## Data Preparation
Cleaned and transformed transaction data, prepared date fields, handled customer identifiers, and separated return and cancellation transactions for relevant analyses.

## Business Recommendations
- Develop retention strategies for one-time customers.
- Segment customers using purchase frequency and monetary value.
- Investigate products with unusually high return activity.
- Evaluate international markets using both revenue and quantity.

## Project Files
- Power BI dashboard: `Online_Retail_Portfolio_Project.pbix`
- Findings report: `Online_Retail_PowerBI_Findings_Insights.pdf`
- Dashboard screenshots: See the screenshots folder.

## Limitations
The dataset does not contain product costs, so actual profit and profit margin cannot be reliably calculated. The 2010 data covers December only, limiting year-over-year comparisons.

## How to View
Download the `.pbix` file and open it in Power BI Desktop.
